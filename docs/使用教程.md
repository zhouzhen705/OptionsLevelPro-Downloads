# Options Level Pro 使用教程

Options Level Pro 是 TradingHub 的 ATAS 指标，用于在图表上绘制期权关键位水平线，并在 2.x 正式版中提供 0DTE 期权热图。公开下载入口按大版本线提供最新版，例如 2.x 线的 `2.0.8` 和 1.x 线的 `1.0.0`。

## 下载

请根据 ATAS 大版本下载对应 DLL：

```text
Options-Level-Pro-2.0.8-ATAS-7.x.dll
Options-Level-Pro-2.0.8-ATAS-8.x.dll
Options-Level-Pro-2.0.8-ATAS-X.dll
```

ATAS 7.x、ATAS 8.x 和 ATAS X 的 DLL 不能混用。

## 安装

1. 关闭 ATAS。
2. 将 DLL 复制到 ATAS Indicators 目录。
3. 重新启动 ATAS。
4. 打开图表并添加 Options Level Pro 指标。
5. 在指标设置中填写授权码。

```text
%AppData%\ATAS\Indicators\
```

## 使用说明

- 指标会绘制当前产品支持的期权关键位水平线。
- 2.x 版本提供 0DTE 期权热图，用于查看盘中期权敞口分布。
- 0DTE 热图只在美东时间工作日 09:30-16:30 请求和绘制；盘外不会向服务器请求热图数据，也不会继续绘制热图。
- 盘中最新 0DTE 热图段会延伸到图表右侧空白区域；没有新 K 线时，最新关键位仍保持可见。
- 0DTE 热图刷新间隔固定为 10 秒，不在指标设置中显示。
- 热图状态文字会显示在静态数据状态文字下方，可通过 `显示热图状态文字` 设置独立关闭。
- 0DTE 热图首次加载会读取本地缓存，再按本地最新时间戳只同步新增快照。
- 静态关键位和 0DTE 热图快照会保存在 `%APPDATA%\ATAS\OLP`，方便指标下次启动时直接读取本地已下载数据。
- 可在指标设置中调整热图开关、状态文字、标签显示、显示窗口、透明度、线条高度、最小宽度和主要颜色。
- 热图显示窗口只限制图表显示范围，不会删除本地已保存历史。
- 请确认图表品种和数据周期符合你的交易计划。
- 如需更换设备，请联系支持重置设备绑定后重新激活。

## 风险提示

Options Level Pro 只显示辅助参考水平，不提供交易信号、投资建议或盈利保证。实盘使用前必须先在模拟账户或回放环境中完整测试。

# Options Level Pro User Guide

Options Level Pro is a TradingHub ATAS indicator that draws options key levels as horizontal chart levels and adds a 0DTE options heatmap in the 2.x stable line. Public download links provide the latest release for each major line, such as `2.0.8` for the 2.x line and `1.0.0` for the 1.x line.

## Download

Download the DLL that matches your ATAS major version:

```text
Options-Level-Pro-2.0.8-ATAS-7.x.dll
Options-Level-Pro-2.0.8-ATAS-8.x.dll
Options-Level-Pro-2.0.8-ATAS-X.dll
```

DLLs for ATAS 7.x, ATAS 8.x, and ATAS X are not interchangeable.

The native heatmap core is embedded in the matching indicator DLL. Install only the one Options Level Pro DLL that matches your ATAS version; do not install a separate native DLL.

原生热图核心已内嵌在对应的指标 DLL 中。只需要安装与你的 ATAS 版本匹配的一个 Options Level Pro DLL，不需要安装单独的 native DLL。

## Installation

1. Close ATAS.
2. Copy the DLL into the ATAS Indicators folder.
3. Restart ATAS.
4. Open a chart and add the Options Level Pro indicator.
5. Enter your license key in the indicator settings.

```text
%AppData%\ATAS\Indicators\
```

## Usage

- The indicator draws supported options key levels on the chart.
- The 2.x line adds a 0DTE options heatmap for intraday options exposure distribution.
- The 0DTE heatmap requests and renders only during weekdays 09:30-16:30 ET; outside that window it does not request heatmap data from the server and does not continue drawing the heatmap.
- The latest intraday 0DTE heatmap segment extends into the right-side chart area, keeping the latest key levels visible when no new candle has printed yet.
- The 0DTE heatmap refresh interval is fixed at 10 seconds and is not shown in indicator settings.
- Heatmap status text appears below the static-data status text and can be hidden independently with the `显示热图状态文字` setting.
- On first load, the 0DTE heatmap reads the local cache and then syncs only new snapshots based on the local latest timestamp.
- Static levels and 0DTE heatmap snapshots are stored under `%APPDATA%\ATAS\OLP`, so the indicator can read previously downloaded data locally on the next start.
- Indicator settings let you adjust the heatmap toggle, status text, label visibility, display window, opacity, line height, minimum width, and main colors.
- The heatmap display window limits only the chart display range and does not delete saved local history.
- Confirm that the chart symbol and timeframe match your trading plan.
- If you need to move devices, contact support to reset the device binding before reactivation.

## Risk Notice

Options Level Pro displays auxiliary reference levels only. It does not provide trading signals, investment advice, or profit guarantees. Test fully in simulation or replay before live trading.
