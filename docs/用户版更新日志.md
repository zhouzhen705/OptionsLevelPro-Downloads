# Options Level Pro 用户版更新日志

本页面记录公开下载中心中的用户可见版本变更。

## 2.0.8

发布状态：正式版。

### 修复

- 盘中最新 0DTE 热图段会继续延伸到图表右侧空白区域。
- 没有新 K 线时，最新热图关键位仍保持可见。
- 盘后和历史日期仍按当天 16:30 ET 截断，不会恢复隔夜延伸。
- 当前公开下载中心按大版本线提供最新版；2.x 线提供 `2.0.8`，1.x 线继续提供 `1.0.0`。

## 2.0.7

发布状态：正式版。

### 新增

- 在静态数据状态文字下方新增 0DTE 热图状态文字。
- 热图状态文字会提示更新时间、盘外暂停、拉取中或暂无数据状态。
- 新增 `显示热图状态文字` 设置开关，可独立关闭热图文字提示，不影响静态关键位线、热图绘制或热图标签。
- 当前公开下载中心按大版本线提供最新版；2.x 线提供 `2.0.7`，1.x 线继续提供 `1.0.0`。

## 2.0.6

发布状态：正式版。

### 更新

- 0DTE 热图只在美东时间工作日 09:30-16:30 请求服务器数据和绘制图表。
- 盘外时间段不再向服务器请求热图数据，也不会继续绘制热图。
- 热图线段会在当天 16:30 ET 截断；静态期权关键位线不受影响。
- 热图刷新间隔固定为 10 秒，不再作为用户可调整设置显示。
- 2.0.6 发布时，公开下载中心按大版本线提供最新版；2.x 线当时提供 `2.0.6`，1.x 线继续提供 `1.0.0`。

## 2.0.5

发布状态：正式版。

### 优化

- 优化 0DTE 热图历史渲染，连续重复快照会在读取、合并、写入缓存和图表绘制前被压缩。
- 图表绘制改为按 key 线性时间线渲染，降低高频盘中 history 导致的卡顿。
- 热图缓存写入改为紧凑 JSON，降低本地缓存体积和后续读取负担。

### 更新

- 2.0.5 发布时，公开下载中心按大版本线提供最新版；2.x 线当时提供 `2.0.5`，1.x 线继续提供 `1.0.0`。

## 2.0.2

发布状态：正式版。

### 新增

- 新增本地 OLP 数据目录 `%APPDATA%\ATAS\OLP`，用于保存静态关键位和 0DTE 热图快照。
- 新增热图显示窗口设置。该设置只限制图表显示范围，不删除本地已保存历史。

### 更新

- 0DTE 热图启动时先读取本地缓存，再只同步新增快照，减少重复下载和图表绘制负载。
- ES 和 NQ 热图快照会一并写入本地；MES 使用 ES 数据，MNQ 使用 NQ 数据。
- 2.0.2 发布时，公开下载中心按大版本线提供最新版；2.x 线当时提供 `2.0.2`，1.x 线继续提供 `1.0.0`。

## 2.0.1

发布状态：正式版。

### 修复

- 补齐 0DTE 热图设置项，包括标签、透明度、线条高度、最小宽度和主要颜色。
- 修复指标端热图缓存行为：首次同步服务器当前缓存窗口，后续轮询只同步新增快照，并保留当前图表会话中已下载的热图数据。

### 更新

- 2.0.1 发布时，公开下载中心已改为按大版本线提供最新版；2.x 线当时提供 `2.0.1`，1.x 线继续提供 `1.0.0`。
- 同一大版本线中的旧小版本变更记录可以继续保留为历史更新日志，但不再作为公开下载入口展示。
- ATAS 7.x、ATAS 8.x 和 ATAS X 的 `2.0.0` 发布包保留在正式版目录中，用于历史支持和人工回滚场景。

## 2.0.0

发布状态：正式版。

### 新增

- 新增 0DTE 期权热图，用于查看盘中期权敞口分布。
- 保留静态期权关键位水平线。
- ATAS 7.x / 8.x / ATAS X 均提供独立正式版 DLL。

## 1.0.0

发布状态：正式版。

### 修复

- 修复 ATAS 7.x / 8.x / ATAS X 图表偶发显示 `0.00` 水平线的问题，确保指标只绘制有效期权关键位。
- 修正 ATAS X 下载包版本号，统一为 `1.0.0`。

### 更新

- ATAS 7.x / 8.x / ATAS X 正式版统一使用完整历史数据文件。
- 本地历史缓存写入时只更新当前品种历史，保留同一文件内其他品种数据。

# Options Level Pro User Changelog

This page records user-visible changes in the public download center.

## 2.0.8

Release status: stable.

### Fixed

- The latest intraday 0DTE heatmap segment now extends into the right-side chart area.
- The latest heatmap key levels remain visible when no new candle has printed yet.
- After-hours and historical sessions remain capped at 16:30 ET and do not regain overnight extension.
- The public download center now provides the latest release for each major line: `2.0.8` for the 2.x line and `1.0.0` for the 1.x line.

## 2.0.7

Release status: stable.

### Added

- Added 0DTE heatmap status text below the static-data status text.
- The heatmap status text shows update time, outside-market pause, fetching, or no-data states.
- Added the `显示热图状态文字` setting so users can hide the heatmap text prompt without affecting static key levels, heatmap rendering, or heatmap labels.
- The public download center now provides the latest release for each major line: `2.0.7` for the 2.x line and `1.0.0` for the 1.x line.

## 2.0.6

Release status: stable.

### Changed

- The 0DTE heatmap requests server data and renders only on weekdays from 09:30 to 16:30 ET.
- Outside the market session, the indicator no longer requests heatmap data from the server and does not continue rendering the heatmap.
- Heatmap segments are capped at 16:30 ET for the session; static options key levels are unaffected.
- The heatmap refresh interval is fixed at 10 seconds and is no longer shown as a user-adjustable setting.
- At the 2.0.6 release, the public download center provided the latest release for each major line: `2.0.6` for the 2.x line at that time and `1.0.0` for the 1.x line.

## 2.0.5

Release status: stable.

### Improved

- Optimized 0DTE heatmap history rendering by collapsing consecutive duplicate snapshots before cache reads, merges, writes, and chart rendering.
- Chart rendering now draws per-key linear timelines to reduce lag with high-frequency intraday history.
- Heatmap cache writes now use compact JSON to reduce local cache size and future read overhead.

### Changed

- At the 2.0.5 release, the public download center provided the latest release for each major line: `2.0.5` for the 2.x line at that time and `1.0.0` for the 1.x line.

## 2.0.2

Release status: stable.

### Added

- Added the local OLP data directory `%APPDATA%\ATAS\OLP` for static levels and 0DTE heatmap snapshots.
- Added a heatmap display-window setting. It limits only the chart display range and does not delete saved local history.

### Changed

- The 0DTE heatmap reads the local cache first and then syncs only new snapshots, reducing repeated downloads and chart rendering load.
- ES and NQ heatmap snapshots are written to the local cache together. MES uses ES data, and MNQ uses NQ data.
- At the 2.0.2 release, the public download center provided the latest release for each major line: `2.0.2` for the 2.x line at that time and `1.0.0` for the 1.x line.

## 2.0.1

Release status: stable.

### Fixed

- Added the missing 0DTE heatmap settings for labels, opacity, line height, minimum width, and main colors.
- Fixed indicator-side heatmap cache behavior: the first load syncs the current server cache window, later polls sync only new snapshots, and downloaded heatmap data remains available during the current chart session.

### Changed

- At the 2.0.1 release, the public download center changed to provide the latest release for each major line: `2.0.1` for the 2.x line at that time and `1.0.0` for the 1.x line.
- Change notes for older minor or patch releases within the same major line may remain available as historical changelog entries, but are no longer shown as public download links.
- The ATAS 7.x, ATAS 8.x, and ATAS X `2.0.0` packages remain in the stable release directory for historical support and manual rollback scenarios.

## 2.0.0

Release status: stable.

### Added

- Added the 0DTE options heatmap for intraday options exposure distribution.
- Retained the static options key levels.
- Provides separate stable DLLs for ATAS 7.x, ATAS 8.x, and ATAS X.

## 1.0.0

Release status: stable.

### Fixed

- Fixed the occasional `0.00` horizontal line on ATAS 7.x / 8.x / ATAS X charts so the indicator only draws valid options key levels.
- Corrected the ATAS X download-package version number to `1.0.0`.

### Changed

- Stable builds for ATAS 7.x / 8.x / ATAS X use the full history data file.
- Local history-cache writes update only the current symbol history and preserve other symbols in the same file.
