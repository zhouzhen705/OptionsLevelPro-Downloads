# Options Level Pro 1.0.0 Release Notes

Target version: ATAS X

Options Level Pro 1.0.0 is the stable release for ATAS X users.

## What's New

- Fixed the occasional `0.00` horizontal line so only valid options key levels are drawn.
- Switched the default data connection to the official Trading Hub HTTPS service.
- Unified the ATAS X download-package version at `1.0.0`.
- Improved history-cache loading with the full history data file.
- Provides a dedicated ATAS X DLL download.

## Recommended Use

Download the DLL that matches your ATAS version. ATAS 7.x, ATAS 8.x, and ATAS X files are not interchangeable.
