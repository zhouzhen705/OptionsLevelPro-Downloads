# Options Level Pro 2.0.0 / ATAS X

This directory contains the Options Level Pro 2.0.0 DLL for ATAS X.
本目录包含适用于 ATAS X 的 Options Level Pro 2.0.0 DLL。

## Files

- ``Options-Level-Pro-2.0.0-ATAS-X.dll`: ATAS X indicator DLL.
- ``SHA256SUMS.txt``: SHA256 checksums for the release files.
- ``Options-Level-Pro-2.0.0-ATAS-X.dll`：ATAS X 指标 DLL。
- ``SHA256SUMS.txt``：发布文件 SHA256 校验值。

The native heatmap calculation core is embedded inside the indicator DLL. Users only install the matching ``Options-Level-Pro-2.0.0-ATAS-X.dll`` file.
原生期权热图计算核心已内嵌在指标 DLL 中，用户只需要安装对应的 ``Options-Level-Pro-2.0.0-ATAS-X.dll`` 文件。

## Status

Current stable release package for ATAS X.
当前 ATAS X 稳定发布包。
