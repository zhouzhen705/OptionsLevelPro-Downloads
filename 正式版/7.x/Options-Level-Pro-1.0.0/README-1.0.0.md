# Options Level Pro 1.0.0 ATAS 7.x 使用说明

本页面说明如何安装并启用适用于 ATAS 7.x 的 Options Level Pro 1.0.0。

## 下载文件

- `Options-Level-Pro-1.0.0-ATAS-7.x.dll`
- [版本说明](RELEASE_NOTES-1.0.0.md)
- [技术信息](BUILD_INFO-1.0.0.md)

## 安装步骤

1. 关闭 ATAS。
2. 下载 `Options-Level-Pro-1.0.0-ATAS-7.x.dll`。
3. 将 DLL 放入 ATAS 的 Indicators 目录。
4. 重新启动 ATAS。
5. 打开图表并添加 Options Level Pro 指标。
6. 在指标设置中输入你的 Trading Hub 授权码。

# Options Level Pro 1.0.0 ATAS 7.x Guide

This page explains how to install and activate Options Level Pro 1.0.0 for ATAS 7.x.

## Downloads

- `Options-Level-Pro-1.0.0-ATAS-7.x.dll`
- [Release notes](RELEASE_NOTES-1.0.0.md)
- [Technical information](BUILD_INFO-1.0.0.md)

## Installation

1. Close ATAS.
2. Download `Options-Level-Pro-1.0.0-ATAS-7.x.dll`.
3. Place the DLL in the ATAS Indicators directory.
4. Restart ATAS.
5. Open a chart and add the Options Level Pro indicator.
6. Enter your Trading Hub license key in the indicator settings.
